🛒 Blinkit Grocery Sales Analysis Dashboard (Excel)
📌 Project Overview

This project presents an interactive Blinkit Grocery Sales Dashboard built using Microsoft Excel. The dashboard analyzes grocery sales performance, outlet performance, product categories, customer ratings, and other key business metrics.

The main objective is to gain meaningful business insights from grocery sales data and help understand sales trends and outlet performance.

🎯 Key Performance Indicators (KPIs)
* Total Sales: ₹12,01,681
* Average Sales: ₹141
* Average Rating: 3.97
* Number of Items: 8,523
* Average Weight: 12.9
  
📊 Dashboard Features
* Outlet Size Analysis: Sales performance across High, Medium, and Small outlets.
* Outlet Type Analysis: Comparison of sales across different supermarket outlet types.
* Product Category Analysis: Sales contribution by different product categories.
* Fat Content Analysis: Comparison between Low Fat and Regular products.
* Year-wise Sales Analysis: Analysis of sales trends based on outlet establishment year.
* Average Sales Analysis: Comparison of average sales by product category and outlet type.
* 
🛠️ Tools & Technologies Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Data Analysis
* Interactive Dashboard Design
  
📈 Key Insights
* The dashboard provides an overview of total grocery sales and average sales.
* Supermarket Type 1 contributes the highest sales among the outlet types shown.
* Low Fat and Regular products are compared to understand sales contribution.
* Outlet establishment year helps identify sales trends over time.
* Product category analysis highlights the contribution of different grocery categories.
  
🎛️ Interactive Filters

The dashboard includes interactive slicers to filter data by:

* Outlet Size
* Outlet Establishment Year
* Item Type
